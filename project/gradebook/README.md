# Մատյան

Ծրագիր ուսուցչի համար. բացում է դասարանի ցուցակը, ցույց է տալիս, թե ով է անցել,
հաշվում է միջինը և պահպանում փոփոխությունները։

> **Սա օրինակելի տարբերակն է։** Եթե 21-րդ օրը ետ ես մնացել, վերցրո՛ւ այն —
> բայց **նախ կարդա՛ ամեն ֆայլը** և հասկացի՛ր, հետո նոր գրի՛ր քոնը։
> Պատճենելը առանց կարդալու օգուտ չի տա։

## Ինչպես գործարկել

```
python main.py
```

## Ֆայլերը

| Ֆայլ | Ի՞նչ է անում | Ի՞նչ չգիտի |
|---|---|---|
| `settings.py` | Բոլոր թվերը, որ կարող ես փոխել | ոչինչ չի անում — միայն պահում է |
| `storage.py` | Կարդում է ֆայլը և գրում ետ | գնահատականների իմաստը |
| `grades.py` | Հաշվարկները՝ միջին, ամենաբարձր, անցավ | ֆայլերի մասին ոչինչ |
| `main.py` | Խոսում է ուսուցչի հետ | ինքը ոչինչ չի հաշվում |

**Կախվածությունները մեկ ուղղությամբ են.** `main` → `grades`, `storage` → `settings`։

`grades.py`-ն **չի** ներմուծում `storage.py`-ն, և դա դիտավորյալ է. այդպես կարող ես
ստուգել հաշվարկները՝ առանց ֆայլ ունենալու.

```
python grades.py
```

Երբ պատասխանը սխալ է, առաջին հարցը մեկն է՝ **հաշվարկո՞ւմ է սխալը, թե՞ տպելու մեջ**։
Այս հրամանը պատասխանում է դրան անվճար։

## Ինչպես փոխել անցողիկ միավորը

Բացի՛ր `settings.py` և փոխի՛ր `PASS_MARK`-ը։ **Ուրիշ ոչինչ։**

## Ինչպես դնել քո դասարանը

1. Ստեղծի՛ր `data/my_class.csv`՝

```
name,grade
Անի,9
Դավիթ,6
```

2. `settings.py`-ում գրի՛ր `CLASS_FILE = "data/my_class.csv"`

**Միայն անուններ կամ սկզբնատառեր։ Առանց ազգանունների, առանց իրական գնահատականների։**

## Երբ ինչ-որ բան չի աշխատում

| Սխալը | Ի՞նչ անել |
|---|---|
| `ModuleNotFoundError: No module named 'settings'` | Չորս ֆայլերը նույն թղթապանակում չեն |
| `❌ ... ֆայլը չգտնվեց` | `settings.py`-ում ֆայլի անունը սխալ է, կամ `data`-ն սխալ տեղում է |
| Հայերենը կոտրված է | `encoding="utf-8"`-ը մոռացվել է |
| Ոչինչ չի տպվում | `main()`-ը չի կանչվել |
