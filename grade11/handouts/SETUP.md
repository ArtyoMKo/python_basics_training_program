# Նախապատրաստում — 11-րդ դասարանի դասընթաց

**Որքան ժամանակ։** Մոտ 10 րոպե։

Լավ նորություն՝ **նոր բան տեղադրելու կարիք չկա**։ Anaconda-ն և VS Code-ը արդեն
քո համակարգչում են 10-րդ դասարանի դասընթացից, և այս դասընթացի երեք գրադարանը
Anaconda-ն արդեն բերել է։

Պետք է միայն **ստուգել**, որ ամեն ինչ տեղում է։

---

## Քայլ 1 — Բացի՛ր VS Code-ը

Եթե այն չկա համակարգչում (նոր համակարգիչ, վերատեղադրում) — անցի՛ր
**«Եթե ամեն ինչ նորից պետք է տեղադրել»** բաժնին ներքևում։

## Քայլ 2 — Սարքի՛ր դասընթացի թղթապանակը

1. `Documents`-ում սարքի՛ր նոր թղթապանակ՝ **`python_grade11`**
2. VS Code-ում՝ **File → Open Folder** → ընտրի՛ր այն

## Քայլ 3 — Պատճենի՛ր ստուգման ֆայլը

Դասավանդողի ուղարկած ֆայլերից պատճենի՛ր **`check_setup.py`**-ը այդ թղթապանակ։

## Քայլ 4 — Բացի՛ր տերմինալը

VS Code-ում՝ **Terminal → New Terminal**։

Ներքևում կբացվի պատուհան։ Այնտեղ գրի՛ր.

```
python check_setup.py
```

և սեղմի՛ր **Enter**։

## Քայլ 5 — Նայի՛ր արդյունքին

Պետք է տեսնես **վեց կանաչ տող**.

```

----------------------------------------------------
✅ Python                       3.11
✅ numpy                        1.26.4
✅ pandas                       2.2.1
✅ matplotlib                   3.8.3
✅ writing files                this folder is writable
✅ drawing a chart              a chart was drawn and saved

✅ All six are green. You are ready for day 1.
```

---

## Եթե կարմիր տող կա

**Մի՛ փորձիր ինքդ ուղղել։** Ուղարկի՛ր դասավանդողին էկրանի նկարը, և մենք
կուղղենք միասին՝ **մինչև առաջին դասը**, տասը րոպեանոց զանգով։

| Կարմիր տող | Սովորաբար նշանակում է |
|---|---|
| `Python` | տերմինալը այլ Python է օգտագործում — ուղղվում է մեկ պարամետրով |
| `numpy` / `pandas` / `matplotlib` | Anaconda-ն ամբողջությամբ չի տեղադրվել |
| `writing files` | թղթապանակը պաշտպանված է — ընտրի՛ր ուրիշը `Documents`-ում |
| `drawing a chart` | հազվադեպ է. գրե՛ք մեզ, լուծումը մեկ տող է |

---

## Եթե ամեն ինչ նորից պետք է տեղադրել

Նույնն է, ինչ 10-րդ դասարանի դասընթացում.

1. **Anaconda** — `anaconda.com/download` → քո համակարգչի տարբերակը →
   տեղադրումը տևում է 10–15 րոպե
2. **VS Code** — `code.visualstudio.com` → **Download**
3. VS Code-ում՝ ձախ սյունակի քառակուսիների նշանը (**Extensions**) → գտի՛ր և
   տեղադրի՛ր **Python** և **Jupyter**

Ապա վերադարձի՛ր **Քայլ 2**-ին։

---

## Պատասխանի՛ր դասավանդողին

Երբ վեց տողն էլ կանաչ են, **ուղարկի՛ր հաղորդագրություն**՝ «պատրաստ եմ»։

> Սա պարտադիր է։ Առանց դրա չենք իմանա, թե ով է պատրաստ, և առաջին դասը
> կսկսվի տեխնիկական խնդիրներով՝ ծրագրավորման փոխարեն։
