## Ա մաս — Քո տվյալները (12 րոպե)

### 1. Սարքի՛ր ֆայլը

`data/` թղթապանակում սարքի՛ր `my_school.csv`՝ ուղիղ նույն սյունակներով.

```
class,student,subject,grade,note
11A,Անի Հակոբյան,Mathematics,8,
11A,Անի Հակոբյան,Physics,7,
```

> **Անունները կարող են հայերեն լինել։** Ֆայլը տվյալ է, ոչ թե կոդ։
> Պահպանելիս ընտրի՛ր **UTF-8** կոդավորումը։

**Պետք չէ ամբողջ դպրոցը։** Մեկ դասարան, հինգ աշակերտ, երկու առարկա — բավական է։
Կարևորը ձևն է, ոչ թե չափը։

### 2. Ասա՛ ծրագրին

`settings.py`-ում՝ **մեկ տող**.

```python
DATA_FILE = HERE / "data" / "my_school.csv"
```

Եվ եթե առարկաներդ այլ են՝

```python
SUBJECTS = ["Մաթեմատիկա", "Ֆիզիկա"]
```

> ⚠️ Եթե առարկաների անունները հայերեն ես գրում, դրանք պետք է **ուղիղ նույնը** լինեն
> ֆայլում և `settings.py`-ում։ Մեկ տառի տարբերությունը՝ և առարկան կկորչի։

### 3. Գործարկի՛ր

```bash
python main.py
```

**Եթե սխալ է տալիս՝ դա լավ է։** Նախորդ նիստում `loading.py`-ում գրեցինք ստուգումներ հենց
այս պահի համար. ֆայլը կասի, թե ինչն է սխալ։

### 4. Հայերեն տառերը գծապատկերում

Եթե գծապատկերում տառերի փոխարեն **քառակուսիներ** են — դա 14-րդ և 15-րդ թեմաների
Մարտահրավերն էր։ `charts.py`-ում, ներմուծումից հետո՝

```python
plt.rcParams["font.family"] = "Arial Unicode MS"
```

macOS-ում սովորաբար `"Arial Unicode MS"`, Windows-ում՝ `"Sylfaen"` կամ `"Arial"`։

## Բ մաս — Ավելացրո՛ւ մեկ բան (22 րոպե)

Ընտրի՛ր **մեկը**։ Ոչ թե երկուսը։

### 1. Մեկ աշակերտի քարտ

Նոր ֆունկցիա `main.py`-ում, որը հարցնում է անուն և տպում այդ աշակերտի
ամբողջ պատկերը՝ բոլոր գնահատականները, միջինը, չանցած առարկաները։

*Որտեղ:* `main.py` (խոսում է մարդու հետ) + `people.py` (եթե նոր մեթոդ է պետք)

### 2. Առարկայի գծապատկեր

Նոր ֆունկցիա `charts.py`-ում, որը մեկ առարկայի համար սարքում է գծապատկեր՝
երեք դասարանը կողք կողքի։

*Որտեղ:* `charts.py`, ապա մեկ կանչ `main.py`-ում

### 3. Հաշվետվությունը ֆայլում

18-րդ թեմայի տեքստային հաշվետվությունը՝ `output/report.txt`։ Նույնը, ինչ
էկրանին է, բայց ֆայլում։

*Որտեղ:* նոր ֆունկցիա `main.py`-ում, կամ նոր ֆայլ՝ `reporting.py`

### 4. Ռիսկի ցուցակը CSV-ով

Այն 12 աշակերտը, ում պետք է ուշադրություն՝ առանձին CSV ֆայլում, որը կարելի է
Excel-ում բացել։

*Որտեղ:* `loading.py` (ֆայլ է գրում) + մեկ կանչ `main.py`-ում
