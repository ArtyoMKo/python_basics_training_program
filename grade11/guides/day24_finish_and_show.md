**Python 11-րդ դասարանի համար · Թեմա 24-ը 24-ից**

Վերջին դասը։ Երեք բան՝ ծրագիրդ դարձնում ես **ուրիշի կողմից գործարկելի**,
ցույց ես տալիս այն, և նայում ենք, թե ուր գնալ հետո։

> **Վերջնական գործնական թեստը հանձնվում է այսօր** — առանձին նիստով, 90–120 րոպե։

## Ա մաս — `README.md` և `requirements.txt` (15 րոպե)

Ծրագիրը, որը միայն դու կարող ես գործարկել, կիսատ ծրագիր է։

### `requirements.txt`

Տերմինալում՝

```bash
pip freeze > all_packages.txt
```

Բայց դա 300 տող կլինի։ Մեզ պետք է **երեքը**։ Սարքի՛ր ֆայլը ձեռքով.

```
numpy==1.26.4
pandas==2.2.1
matplotlib==3.8.3
```

Տարբերակները վերցրո՛ւ 20-րդ թեմայի `pip show`-ից — **քո համակարգչի թվերը**, ոչ թե սրանք։

### `README.md`

Չորս բաժին։ Ավելին պետք չէ։

```markdown
# Կիսամյակի հաշվետվություն

Կարդում է դպրոցի գնահատականների ֆայլը և սարքում կիսամյակի
հաշվետվությունը՝ միջիններ ըստ դասարանի և առարկայի, ռիսկի ցուցակ,
և երկու գծապատկեր։

## Ինչ է պետք

Python 3.11 և երեք գրադարան՝

    pip install -r requirements.txt

## Ինչպես գործարկել

    python main.py

## Տվյալների ֆայլը

`data/my_school.csv`, հինգ սյունակով՝

    class,student,subject,grade,note
    11A,Անի Հակոբյան,Mathematics,8,

Ֆայլի ճանապարհը փոխվում է `settings.py`-ի `DATA_FILE` տողում։
```

> **Գրի՛ր այն այնպես, ինչպես կբացատրեիր գործընկերոջդ**, ոչ թե ինչպես
> փաստաթղթում։ Եթե նախադասությունը չես ասի բարձրաձայն — մի՛ գրիր։

**Սա օրվա իսկական ստուգումն է։**

2. Նա գործարկում է այն՝ **միայն քո `README.md`-ով**

4. Նա գրում է, թե որտեղ խրվեց

Ապա փոխվո՛ւմ եք տեղերով։

> **Ամենահաճախ հանդիպող երեք խնդիրը.**
> ծրագիրը փնտրում է ֆայլ, որը միայն քո համակարգչում է ·

> տվյալների ֆայլը թղթապանակում չկա, որովհետև այն չես ուղարկել

Ուղղի՛ր այն, ինչ նա գտավ։ **Սա ծրագրավորման իսկական աշխատանքն է։**

## Դ մաս — Այն գրադարանները, որոնք միայն անվանեցինք (12 րոպե)

Աշակերտների ծրագրի 21-րդ թեմայում նշված են գրադարաններ, որոնք այս դասընթացում
**չենք օգտագործել**։ Ահա թե ինչ են դրանք, և ինչու չեն պետք քեզ հիմա։

| Անուն | Ինչ է անում | Պե՞տք է քեզ |
|---|---|---|
| **scikit-learn** | մեքենայական ուսուցում՝ կանխատեսում տվյալներից | Ոչ 10–11-րդ դասարանի համար։ Թեմայում հիշատակված է, բայց որպես ծանոթություն |
| **PyTorch**, **TensorFlow** | նեյրոնային ցանցեր | Ոչ։ Սրանք համալսարանական մակարդակ են |
| **seaborn** | ավելի գեղեցիկ գծապատկերներ | Ոչ։ Matplotlib-ը բավական է, և այն արդեն գիտես |
| **Kaggle**, **Hugging Face** | տվյալների և մոդելների կայքեր | Ոչ։ Օգտակար են, բայց ծրագրավորում չեն |
| **Anaconda**, **Docker** | միջավայրեր | Anaconda-ն արդեն օգտագործում ես։ Docker-ը՝ ոչ |

> **Կարևոր բան, որ պետք է ասել աշակերտներին։** Այս անունները դասագրքում կան, և
> երեխաները կհարցնեն։ Ճիշտ պատասխանը **ոչ թե «դա դժվար է»**, այլ՝
> «դա նույն Python-ն է, որ գիտես, պարզապես ուրիշի գրած ֆունկցիաներով։
> Երբ պետք գա՝ կսովորես մեկ օրում, որովհետև հիմքը արդեն ունես»։
