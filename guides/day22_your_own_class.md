## Քայլ 2 — `save_class`

Բացի՛ր `storage.py`-ն և ավելացրո՛ւ՝

```python
def save_class(class_grades, file_name=settings.CLASS_FILE):
    """Գրում է բառարանը ետ ֆայլ՝ նույն ձևաչափով։"""
    path = Path(file_name)

    lines = ["name,grade"]
    for student_name, grade in class_grades.items():
        lines.append(f"{student_name},{grade}")

    path.write_text("\n".join(lines) + "\n", encoding="utf-8")

    print(f"✅ Պահպանվեց՝ {file_name} ({len(class_grades)} աշակերտ)")
```

Երեք բան.

- `lines = ["name,grade"]` — սկսում ենք վերնագրով, որպեսզի ֆայլը նույն ձևաչափով լինի։
- `"\n".join(lines)` — ցուցակը դարձնում է մեկ տեքստ՝ տողերը բաժանելով նոր տողի նշանով։
- `encoding="utf-8"` — **նորից պարտադիր**։ Առանց դրա հայերենը կկոտրվի գրելիս։

✅ **ՍՏՈՒԳՈՒՄ։** Գործարկի՛ր՝

```
python storage.py
```

Ոչինչ չպետք է փոխվի — `save_class`-ը դեռ ոչ ոք չի կանչում։

## Քայլ 3 — Կապի՛ր այն մենյուին

Բացի՛ր `main.py`-ն։ Ավելացրո՛ւ երկու հրաման մենյուին՝

```python
def add_grade(class_grades):
    """Հարցնում է անուն և գնահատական, ավելացնում կամ ուղղում է։"""
    student_name = input("Աշակերտի անունը՝ ").strip()
    if not student_name:
        print("Անունը դատարկ է — ոչինչ չավելացվեց։")
        return

    answer = input("Գնահատականը (1-10)՝ ").strip()
    if not answer.isdigit():
        print("Դա թիվ չէ — ոչինչ չավելացվեց։")
        return

    grade = int(answer)
    if grade < 1 or grade > 10:
        print("Գնահատականը պետք է լինի 1-ից 10 — ոչինչ չավելացվեց։")
        return

    class_grades[student_name] = grade
    print(f"{student_name} — {grade}։ Պահպանելու համար ընտրի՛ր 4։")
```

Սա ուղիղ 15-րդ օրվա ստուգումներն են՝ `.isdigit()` և միջակայքի ստուգումը։
**Ամեն սխալ ունի իր առանձին հաղորդագրությունը** — «սխալ մուտք» ոչինչ չի ասում։

Հետո մենյուում՝

```python
        print("1 — ցույց տալ մատյանը")
        print("2 — ցույց տալ չանցածներին")
        print("3 — ավելացնել կամ ուղղել գնահատական")
        print("4 — պահպանել")
        print("5 — դուրս գալ")
```

և համապատասխան `elif`-երը՝

```python
        elif choice == "3":
            add_grade(class_grades)
        elif choice == "4":
            storage.save_class(class_grades)
```

✅ **ՍՏՈՒԳՈՒՄ։** Գործարկի՛ր `python main.py`, ավելացրո՛ւ աշակերտ (3),
պահպանի՛ր (4), դուրս արի (5), գործարկի՛ր **նորից**, տպի՛ր մատյանը (1)։

**Նոր աշակերտը այնտեղ է։** Դա է ամբողջ այսօրվա իմաստը։

## Ի՞նչ ես սովորել այսօր

- `path.read_text(encoding="utf-8")` և `path.write_text(...)` — կարդալ և գրել։
- **`encoding="utf-8"`-ը պարտադիր է** հայերենի համար, և՛ կարդալիս, և՛ գրելիս։
- `line.split(",")` — կտրում է տողը ստորակետով։
- Ֆայլը ստուգի՛ր, նախքան բացելը՝ `if not path.exists():`։
- **Մեկ տող `settings.py`-ում փոխեց ամբողջ ծրագրի տվյալները։**
