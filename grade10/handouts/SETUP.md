# Կարգավորում — ինչպես պատրաստել համակարգիչը

**Կարդա՛ սա առաջին դասից առաջ։** Եթե ստացվի տանը — հիանալի է։ Եթե չստացվի — նույնպես
նորմալ է, առաջին դասն ուղիղ դրա համար է։ Ոչինչ չես կոտրի։

**Որքան ժամանակ։** Մոտ 40 րոպե, որից 30-ը սպասում ես ներբեռնմանը։
**Որքան տեղ։** Մոտ **5 ԳԲ** ազատ տեղ սկավառակի վրա։
**Որքան ինտերնետ։** Մոտ **1 ԳԲ** ներբեռնում։

> Եթե 5 ԳԲ ազատ տեղ չկա, կամ ինտերնետը դանդաղ է՝ **մի՛ սկսիր տանը**։ Ասա ուսուցչին.
> գրի՛ր դասավանդողին **մինչև առաջին նիստը** — կզանգենք և միասին կլուծենք։
> Դասընթացը ամբողջությամբ հեռավար է, ուստի ֆլեշ-կրիչ չի լինի։

Երկու ծրագիր ենք տեղադրում, և դրանից հետո՝ ոչ մի բան, ամբողջ դասընթացի ընթացքում։

| Ինչ | Ինչի համար |
|---|---|
| **Anaconda** | Ինքը՝ Python-ը, և այն ամենը, ինչ պետք է տետրերի համար |
| **VS Code** | Պատուհանը, որտեղ գրում ենք։ Բոլոր 18 նիստը՝ նույնը |

# Windows-ի համար

## Քայլ 1 — Տեղադրել Anaconda

1. Բացի՛ր բրաուզերը և գնա՛ **anaconda.com/download**
2. Կտտացրու կանաչ **Download** կոճակին։ Եթե հարցնում է էլ․ հասցե, ներքևում կա
   **skip registration** հղումը — կարող ես բաց թողնել։
3. Ներբեռնումը մոտ **1 ԳԲ** է։ Դպրոցի ինտերնետով կարող է տևել կես ժամ։
   **Սա նորմալ է։ Ծրագիրը կախված չէ։**
4. Բացի՛ր ներբեռնված ֆայլը։ Կբացվի պատուհան՝ **Next** կոճակով։
5. **Ոչինչ մի՛ փոխիր։** Սեղմի՛ր Next → I Agree → **Just Me** → Next → Next → Install։
6. Տեղադրումը տևում է 5–10 րոպե։ Վերջում՝ Next → Finish։

✅ **Ստուգում։** Windows-ի Start ընտրացանկում գրի՛ր `Anaconda`։ Պետք է հայտնվի
**Anaconda Navigator** անունով ծրագիր։ Բացելու կարիք չկա — բավական է, որ այնտեղ է։

> **Եթե «Just Me»-ն չկա կամ տեղադրումը թույլ չի տալիս** — դա նշանակում է, որ դպրոցի
> համակարգիչը սահմանափակված է։ Դա քո մեղքը չէ։ Ասա՛ ուսուցչին առաջին դասից առաջ։

## Քայլ 2 — Տեղադրել VS Code

1. Գնա՛ **code.visualstudio.com**
2. Կանաչ **Download for Windows** կոճակը։ Սա փոքր է — մեկ-երկու րոպե։
3. Բացի՛ր ֆայլը։ Ընդունի՛ր պայմանները, հետո՝ Next → Next → Install → Finish։

✅ **Ստուգում։** VS Code-ը բացվում է և ցույց է տալիս «Get Started» էջը։

## Քայլ 3 — Երկու ընդլայնում

VS Code-ի **ձախ եզրին** կա ուղղահայաց շերտ՝ հինգ-վեց պատկերակով։ Պետք է չորրորդը —
չորս քառակուսի, որոնցից մեկը դուրս է եկել։ Դա **Extensions**-ն է։

1. Կտտացրու դրան։ Վերևում կբացվի որոնման դաշտ։
2. Գրի՛ր `Python`։ Առաջին արդյունքը՝ **Python**, հեղինակը՝ **Microsoft**։ Սեղմի՛ր
   **Install**։
3. Ջնջի՛ր որոնումը, գրի՛ր `Jupyter`։ Առաջինը՝ **Jupyter**, հեղինակը՝ **Microsoft**։
   Սեղմի՛ր **Install**։

✅ **Ստուգում։** Երկուսի վրա էլ **Install**-ի փոխարեն այժմ գրված է **Uninstall** կամ
հայտնվել է ատամնանիվի պատկերակ։

## Քայլ 4 — Ստեղծել քո թղթապանակը

1. Բացի՛ր **File Explorer**-ը, գնա՛ **Documents**։
2. Աջ կտտոց → New → Folder։ Անվանի՛ր ուղիղ այսպես՝ **`python_course`**
   (փոքրատառ, բացատի փոխարեն՝ `_`)։

**Այս մեկ թղթապանակում է լինելու ամեն ինչ՝ բոլոր 18 նիստը։** Նոր թղթապանակ ամեն նիստ
չենք ստեղծում։

## Քայլ 5 — Բացել թղթապանակը VS Code-ում

VS Code → **File → Open Folder…** → ընտրի՛ր `Documents\python_course` → **Select Folder**։

Եթե հարցնում է «Do you trust the authors?» — սեղմի՛ր **Yes, I trust the authors**։

✅ **Ստուգում։** VS Code-ի ձախ կողմում վերևում գրված է **PYTHON_COURSE**։

# Mac-ի համար

## Քայլ 1 — Տեղադրել Anaconda

1. Գնա՛ **anaconda.com/download**
2. Կանաչ **Download** կոճակը։ Կայքը ինքն է ընտրում ճիշտ տարբերակը։
   Եթե հարցնում է էլ․ հասցե՝ ներքևում կա **skip registration**։
3. Ներբեռնումը մոտ **1 ԳԲ** է և կարող է տևել կես ժամ։ **Սա նորմալ է։**
4. Բացի՛ր ներբեռնված `.pkg` ֆայլը։
5. **Ոչինչ մի՛ փոխիր։** Continue → Continue → Agree → **Install for me only**
   → Install։
6. Կարող է հարցնել Mac-ի գաղտնաբառը։ Դա քո համակարգչի գաղտնաբառն է։

✅ **Ստուգում։** Սեղմի՛ր **Cmd + Space**, գրի՛ր `Anaconda`։ Պետք է հայտնվի
**Anaconda Navigator**։ Բացելու կարիք չկա։

## Քայլ 2 — Տեղադրել VS Code

1. Գնա՛ **code.visualstudio.com** → **Download for Mac**։
2. Ներբեռնվածը բացվում է որպես `Visual Studio Code` պատկերակ։
3. **Քաշի՛ր այն `Applications` թղթապանակ։** Առանց դրա ամեն անգամ նորից կներբեռնվի։

✅ **Ստուգում։** Cmd + Space → `Visual Studio Code` → բացվում է։

## Քայլ 3 — Երկու ընդլայնում

VS Code-ի **ձախ եզրին** կա ուղղահայաց շերտ։ Պետք է չորս քառակուսու պատկերակը —
**Extensions**։

1. Գրի՛ր `Python` → առաջինը, հեղինակը՝ **Microsoft** → **Install**։
2. Գրի՛ր `Jupyter` → առաջինը, հեղինակը՝ **Microsoft** → **Install**։

## Քայլ 4 — Ստեղծել քո թղթապանակը

Finder → **Documents** → աջ կտտոց → New Folder → անվանի՛ր **`python_course`**։

## Քայլ 5 — Բացել թղթապանակը VS Code-ում

VS Code → **File → Open Folder…** → `Documents/python_course` → **Open**։
«Do you trust the authors?» → **Yes**։

# Քայլ 6 — Ամենակարևոր քայլը (երկու համակարգչի համար էլ)

Ուսուցիչը կտա քեզ `day01_first_program.ipynb` ֆայլը։ Դի՛ր այն `python_course`
թղթապանակի մեջ և բացի՛ր VS Code-ից՝ ձախ ցանկում կտտացնելով անվան վրա։

**Վերևի աջ անկյունում կտեսնես կոճակ՝ «Select Kernel»։**

1. Կտտացրու դրան։
2. Ընտրի՛ր **Python Environments…**
3. Ցուցակում ընտրի՛ր այն, որի մեջ գրված է **base** կամ **anaconda3**։

> 🛑 **Կարդա՛ սա։** Սա դասընթացի ամենահաճախ հանդիպող խնդիրն է։
>
> **Ամեն անգամ, երբ բացում ես նոր տետր, պետք է անել այս ընտրությունը։**
>
> Եթե տետրը ասում է, որ ինչ-որ բան տեղադրված չէ, չնայած որ ամեն ինչ տեղադրված է —
> **նախ ստուգիր kernel-ը**, հետո նոր փնտրիր այլ պատճառ։ Տասը դեպքից ինը դա է։

✅ **Ստուգում։** «Select Kernel»-ի փոխարեն վերևի աջում այժմ գրված է
**Python 3.1x.x («base»)** կամ նման բան։

# Քայլ 7 — Ստուգել, որ ամեն ինչ աշխատում է

Առաջին դասին ուսուցիչը կտա `check_setup.py` ֆայլը։ Դի՛ր այն `python_course`
թղթապանակի մեջ, բացի՛ր և սեղմի՛ր **▷** կոճակը վերևի աջում (կամ աջ կտտոց →
**Run Python File in Terminal**)։

Պետք է տեսնես վեց կանաչ տող՝

```
✅ 1/6  Python 3.12.7
✅ 2/6  Anaconda
✅ 3/6  Text and files work - Hello, world
✅ 4/6  Folder: python_course
✅ 5/6  Writing and reading a file works
✅ 6/6  sample_class.csv - 12 students

Everything is ready.
```

> **Ինչո՞ւ է այս տեքստը անգլերեն։** Դասընթացի բոլոր բացատրությունները հայերեն են։
> Բայց **կոդի ներսում ամեն բան անգլերեն է** — բառերը, անունները, տպվող տեքստը։
> Այդպես քո գրած կոդը նույնն է, ինչ աշխարհի ցանկացած Python, և կարող ես ինտերնետում
> պատասխան փնտրել, երբ խնդիր ունենաս։

Եթե որևէ տող կարմիր է, այնտեղ գրված է **ուղիղ այն, ինչ պետք է անել**։ Կարդա՛ այն
և ասա՛ ուսուցչին, եթե պարզ չէ։

2. **File → Open Recent → python_course**

# Երբ ինչ-որ բան չի աշխատում

| Ինչ ես տեսնում | Ինչ է դա նշանակում | Ինչ անել |
|---|---|---|
| «Select Kernel» — և կոդը չի աշխատում | Kernel ընտրված չէ | Քայլ 6 |
| `ModuleNotFoundError` | Սխալ kernel է ընտրված | Քայլ 6, նորից |
| `NameError` | Վերևի բջիջը չի գործարկվել | Գործարկի՛ր բոլոր բջիջները վերևից ներքև |
| `FileNotFoundError` | Սխալ թղթապանակում ես | File → Open Folder → `python_course` |
| Ներբեռնումը «կանգնել է» | Չի կանգնել։ 1 ԳԲ է | Սպասի՛ր։ Եթե մեկ ժամից ավելի է՝ գրի՛ր դասավանդողին |
| Չի թողնում տեղադրել | Համակարգիչը սահմանափակված է | Ասա՛ ուսուցչին — կա այլ ճանապարհ |

Այս վեցից չորսը կապ չունեն քո գրած կոդի հետ։ Դա նորմալ է։ Ծրագրավորման մեջ
ժամանակի մեծ մասը կորչում է կարգավորումների վրա, ոչ թե կոդի։

# Երկու բան, որ պետք չէ անել

  միասին շփոթություն են ստեղծում։

  առաջին օրից հետո։ Եթե ինչ-որ ուղեցույց ինտերնետում ասում է՝ արա, այս դասընթացի
  համար պետք չէ։
