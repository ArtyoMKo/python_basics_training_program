## Քայլ 2 — Տեղափոխի՛ր ֆունկցիաները

Բացի՛ր 19-րդ թեմայի տետրը — այն, որտեղ ամբողջ ծրագիրը հավաքեցինք։
Գտի՛ր այն բջիջը, որտեղ ֆունկցիաներն են։

**Պատճենի՛ր ամբողջը և տեղադրի՛ր `grades.py`-ի մեջ։**

Ֆայլը պետք է սկսվի այսպես.

```python
PASS_MARK = 4


def average_of(grades):
    """Return the average of a list of grades."""
    total = 0
    for grade in grades:
        total = total + grade
    return round(total / len(grades), 1)


def has_passed(grade, pass_mark=PASS_MARK):
    """Return True if this grade is a pass."""
    return grade >= pass_mark
```

Պահի՛ր՝ **Ctrl + S** (Mac-ում՝ **Cmd + S**)։

> **Ուշադրություն։** Եթե ֆայլի անվան կողքին սպիտակ կետ է, դա նշանակում է՝ չի պահպանվել։
> Սա տետրում չկար, և առաջին օրերին հաճախ մոռացվում է։

✅ **ՍՏՈՒԳՈՒՄ։** Ֆայլում չորս ֆունկցիա է, կետ չկա անվան կողքին։

## Քայլ 3 — Բացի՛ր տերմինալը

Տերմինալը պատուհան է, որտեղ հրաման ես գրում համակարգչին։

VS Code-ում այն արդեն ներսում է՝ **Ctrl + `** (այն ստեղնը, որ Tab-ի վերևում է)։

Կամ՝ ընտրացանկից՝ **Terminal → New Terminal**։

Ներքևում կբացվի պատուհան՝ մի քանի բառով և առկայծող գծիկով։

✅ **ՍՏՈՒԳՈՒՄ։** Տերմինալում գրի՛ր այս հրամանը և սեղմի՛ր Enter՝

```
python --version
```

Պետք է պատասխանի `Python 3.1x.x`։

> **Եթե ասում է «command not found» կամ «not recognized»**, փորձի՛ր `python3 --version`։
> Եթե դա աշխատի, ապա այս ուղեցույցում ամենուր `python`-ի փոխարեն գրի՛ր `python3`։
> Եթե ոչ մեկը չաշխատի՝ ձեռք բարձրացրու։

տարբեր բաներ են։ Դու սահմանեցիր չորս ֆունկցիա և ոչ մեկը չկանչեցիր։

## Քայլ 5 — Ստիպի՛ր նրան տպել

Ֆայլի **վերջում** ավելացրո՛ւ՝

```python
test_class = {"Ani": 9, "Davit": 6, "Nare": 10, "Aram": 3}

print("average:", average_of(list(test_class.values())))
print("highest:", highest_of(test_class))
```

Պահի՛ր և գործարկի՛ր նորից՝ `python grades.py`

Հիմա տպում է։

✅ **ՍՏՈՒԳՈՒՄ։** Տերմինալում տեսնում ես միջինը և ամենաբարձրը։

> **Ուշադրություն։** Տետրում բջիջի վերջին տողը ինքն իրեն ցույց էր տրվում։
> **Ֆայլում դա չի աշխատում։** Այստեղ ամեն բան, որ ուզում ես տեսնել, պետք է `print`-ի մեջ լինի։

## Քայլ 6 — `if __name__ == "__main__":`

Մի խնդիր կա։ Այդ երկու `print`-ը ստուգման համար է։ Բայց այս նիստի երկրորդ կեսին այս ֆայլը ներմուծելու ենք
ուրիշ ֆայլից, և այդ ժամանակ **չենք ուզում**, որ դրանք տպվեն։

Լուծումը մեկ տող է։ Փաթաթի՛ր ստուգումը այսպես՝

```python
if __name__ == "__main__":
    test_class = {"Ani": 9, "Davit": 6, "Nare": 10, "Aram": 3}

    print("average:", average_of(list(test_class.values())))
    print("highest:", highest_of(test_class))
```

Կարդացվում է այսպես.

> **«Եթե այս ֆայլը գործարկվում է ուղիղ — արա՛ սա։ Իսկ եթե ուրիշ ֆայլ է ինձ ներմուծում —
> մի՛ արա»։**

Անգիր անելու կարիք չկա։ Պատճենի՛ր այն ամեն անգամ, երբ ֆայլում ստուգում ես գրում։
Հուշաթերթում այն կա։

✅ **ՍՏՈՒԳՈՒՄ։** `python grades.py`-ն դեռ տպում է նույնը։ Այս նիստի երկրորդ կեսին կտեսնես, թե ինչու էր
դա պետք։
